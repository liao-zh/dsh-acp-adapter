## 记录

### 2026-11-12 适配 DSH 0.2.2-rc.2（提交 6dc3715）

- 类型：适配
- 文件：`package.json`、`src/`（29 个文件）、删除 9 个文件
- 为什么：DSH 0.2.1-rc.4 → 0.2.2-rc.2 有 20+ 处破坏性变更，插件激活即报
  `ctx.get(...)?.tryMembership is not a function`。
- 上游状态：**未修**（上游 0.2.1-rc.4.1 停在 10-28，无 0.2.2 兼容版）
- 可丢弃：否（丢弃后插件在 0.2.2 上无法启动）

主要变更：

| 根因 | 处数 | 处理 |
|---|---|---|
| `LlmError` 构造器只收内置 code | 92 | 全部改 `LlmError.fromFailure({ message, code })` |
| `tools.execute` 单次 → 批次 `ToolBatchInput` | 1 | `calls:[{type:'tool-call', id, name, arguments: JSON.stringify(args)}]`，结果取 `batch.results[0]`，`additionalContexts` 合并 |
| `tools.executionMode` 删除 | 1 | 改用 `definition.isConcurrencySafe` |
| `agentTeams` roster 整套删除 | 22 | `tryMembership`/`listMembers` → `subagents.rootOf` / `namesOf` / `isEnabled` |
| `stateOf(session, key)` 废弃（返回 unknown） | 10 | 自注册单元走 `ProjectionHandle.stateOf`；宿主单元走 `snapshot().values` |
| `register()` 变异步返回 handle | 2 | 捕获 handle 后读取 |
| `agents.roots()` / `isOwnedBy()` 删除 | 6 | `subagents.rootOf` + `parentSession` 重建 |
| `ProjectionDefinition` 需 2 个泛型参数 | 2 | 补状态类型 |
| zod 4.4.3 与宿主 4.6.6 双实例 | — | 升到 4.6.6 |
| `modelSelection.pending` → `next` | 1 | 字段改名 |
| `title` 投影删除 | 1 | 改用 `useSessions` 的 `SessionListEntry.title` |
| `subagents/interruptByParent` → `interruptByUser` | 2 | 端点改名，参数 3 → 1 |
| `getAnchorRect` → `anchor` 元素（CSS 锚点） | 2 | 删除测量回调 |
| `NativeOwner.fileMentions` 删除 | 2 | 删字段 |
| `PermissionSelection` 结构变 `{currentValue}` | 1 | 对齐 |
| `files` 缺 `lib/typert.remote-client.d.ts.map` 校验 | 1 | 补进 `package.json` |

删除的文件（能力在 0.2.2 中整体消失，无数据源）：
`host/teams/{management,member-models,member-model-tools,member-model-facts}.ts`、
`client/ui/{AcpTeamManagement,TeamMemberModelControl}.ts` 及 3 个测试。

功能影响：
- 保留：ACP 会话、工具桥、subagent、审批、诊断、`team_task_*` 任务板
- 降级：Team 成员面板不挂载（`TeamProjection` 只剩 `enabled`/`tasks`/`failure`）
